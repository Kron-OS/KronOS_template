=== First real E2E attempt: real "Not Found" ===

=== Second real E2E attempt: real 400, "Invalid redirect_uri" (via nginx access log) ===
  GET /realms/kronos/protocol/openid-connect/auth?...&redirect_uri=
  https%3A%2F%2Fkronos.local%3A18443%2Fsilent-check-sso.html... -> 400
Real cause: docker/keycloak/kronos-realm.json's "kronos-frontend" client
redirectUris/webOrigins are ["https://kronos.local/*"] /
["https://kronos.local"] -- origin-exact-match on scheme+host+PORT (the
`/*` wildcard only covers the path), and this PoC's local-verification-only
port remap (:18443, needed only because this host already runs the real
dev stack on the standard ports) doesn't match. Real CI (a clean GitHub
Actions runner with no conflicting stack) would use the file's own
standard 443/8443 ports and never hit this -- confirmed this is a
local-verification-only artifact, not a real gap in the shared realm file.
Fixed for this isolated instance only, via a live Admin REST PUT (the same
kind of post-import client patch keycloak-init/provision_keycloak_org.sh
already do for organizations) adding the :18443 origin -- the shared
kronos-realm.json file itself was never touched.

=== Third real E2E attempt: real login succeeded, app stuck loading Cases list ===

  pydantic_core._pydantic_core.ValidationError: 4 validation errors for Settings
  POST /auth/refresh -> 401, then 500
Real, reproduced finding: src/external/routes/auth.py's /auth/refresh
instantiates a fresh Settings() per REQUEST (not just at process startup),

first kronos-backend attempt wasn't just a cosmetic startup warning -- it's
a genuine 500 on every real refresh call, which the frontend's own
silent-refresh/session-bootstrap logic depends on. Fixed: celery_broker_url/
result_backend point at the real redis already in this file (DB1/DB2, no
functional need for a dedicated broker for a login-only flow); vault_url/
token given syntactically-valid placeholder values -- confirmed nothing in
a login-only flow actually calls Vault (fix worked with no Vault service
present at all).
